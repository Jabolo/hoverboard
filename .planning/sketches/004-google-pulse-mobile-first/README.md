# Sketch 004: Google Pulse Mobile First

## Design Question

Can the Google Pulse direction create a memorable visual anchor on desktop while keeping the mobile page compact, legible, and conversion-oriented?

## How to View

Open `.planning/sketches/004-google-pulse-mobile-first/index.html` from the repository root or serve the repository with a local HTTP server so the official image assets resolve.

## Focused Direction

- **A: Google Pulse** — stacked mobile hero with a strong three-line headline, animated event poster, compact event facts, and ticket selection; the desktop layout gives the poster and orbit system more room.

## What to Look For

Compare the emotional first impression with Neon Terminal. Check whether the poster adds enough energy, whether the date remains easy to find, and whether the ticket choices feel like a natural continuation of the hero.

## Verification

- Reviewed at 412×915 (Pixel 7 emulation), 393×852 (iPhone 15 emulation), and desktop widths.
- Checked mobile horizontal overflow, 50px CTA tap targets, menu state, ticket selection, poster pulse interaction, countdown label, theme switcher, viewport controls, and annotation mode.
- Final browser pass: zero console errors, zero network errors, and a clean hidden-content prompt-injection scan.
