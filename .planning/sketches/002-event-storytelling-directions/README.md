# Sketch 002: Event Storytelling Directions

## Design Question

Should the landing page earn its energy from a useful event-information system or from a distinctive visual poster treatment?

## Variants

- **A: Stage Timeline** — a programme-like horizontal rail connects the date, countdown, community, and ticket CTA.
- **B: Neon Terminal** — a dark technical interface treats event facts as live system signals and turns the ticket CTA into a clear command.
