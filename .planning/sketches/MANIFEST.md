# Sketch Manifest

## Design Direction

Explore a more confident desktop landing page for GDG DevFest Warsaw 2026. The current mobile composition has a useful rhythm, but the desktop view needs a stronger visual anchor, more intentional use of the wide canvas, and a clearer sense of event energy. These sketches test five directions from expressive Google-color geometry to community imagery and technical event systems. The event date, concise tagline, official GDG/GDG Warsaw identity, countdown, ticket CTA, and current catalogue remain grounded in the real site.

## Reference Points

- Current Hoverboard-based website and its Polymer/Lit + Material Web stack.
- Google Developer Groups visual language: primary blue, Google four-color accents, friendly community tone.
- Official local assets in `public/images/logos/`, `public/images/team/`, and `public/images/backgrounds/home-2026.png`.
- Current event facts: November 21, 2026; 300 attendees; 1 day; sessions and tracks TBA; Early Bird, Regular, LastBird, Supporter, and Patron tickets.
