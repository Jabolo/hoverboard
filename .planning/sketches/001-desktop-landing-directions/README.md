# Sketch 001: Desktop Landing Directions

## Design Question

How can the desktop landing page use its wide canvas more intentionally while keeping the event identity, date, tagline, and registration CTA immediately legible?

## Variants

- **A: Google Pulse** — dark full-bleed stage, Google-color motion lines, and a floating event status card.
- **B: Editorial Poster** — warm editorial canvas, oversized date typography, image crop, and a tactile ticket card.
- **C: Community Mosaic** — people-first collage using the current team portraits, with a strong communal headline.

## How to View

Open `.planning/sketches/001-desktop-landing-directions/index.html` in a browser. Use the variant tabs, the viewport buttons, and the annotation toggle in the floating toolbar.

## Notes

This is a throwaway HTML exploration. It does not modify the production site and contains no real registration form submission.
